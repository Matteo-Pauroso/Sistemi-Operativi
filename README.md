# Sistemi Operativi

Appunti personali del corso **Sistemi Operativi**, raccolti e organizzati da **Matteo Pauroso**.
La repo contiene definizioni, dimostrazioni, esercizi, schemi riassuntivi e osservazioni utili allo studio della materia.

Non sostituiscono le lezioni ufficiali né i testi consigliati dal docente.
Usali con spirito critico.

______________________________________________________________________

## Informazioni utili

L'attuale corso si svolge principalmente con l'utilizzo di Linux e C.

Nel mio caso utilizzo la WSL su Windows 10 con la distro Ubuntu.
